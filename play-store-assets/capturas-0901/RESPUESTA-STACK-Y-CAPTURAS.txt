1) LA VERDAD DEL STACK: es CAPACITOR. No hay Kotlin ni Jetpack Compose.
--------------------------------------------------------------------------------
La descripción del repo ("Kotlin + Jetpack Compose") es INCORRECTA y hay que
corregirla. El README y la detección de lenguaje de GitHub están en lo cierto.

Evidencia (revisada sobre el árbol actual):
- TODO el código nativo de la app es UN archivo:
  android/app/src/main/java/com/oraculounificado/app/MainActivity.java
  → `public class MainActivity extends BridgeActivity` (BridgeActivity de
  Capacitor). El WebView lo crea Capacitor; MainActivity solo registra 4
  puentes @JavascriptInterface (AndroidClipboard, AndroidShare, AndroidLocale,
  AndroidOpenUrl) y en build debug activa setWebContentsDebuggingEnabled.
- grep -ri "compose|kotlin" android/app/build.gradle android/variables.gradle
  → 0 resultados. Sin dependencias Compose. (kotlinx.coroutines aparece en el
  APK solo como dependencia TRANSPONENTE del runtime de Capacitor.)
- capacitor.config.json → "webDir": "www". La UI completa es HTML5 + CSS3 +
  ES modules vanilla servida en el WebView (sin frameworks).
- Stack real: Capacitor 8 · WebView (Chromium) · Swiss Ephemeris WASM ·
  SQLite (sql.js) en el lado web · Gradle 8 / Java 17 · R8/ProGuard ·
  worker IA en Cloudflare (proxy a Gemini).

Descripción CORREGIDA propuesta para el repo (y borrador que debe contar lo mismo):

  "App Android híbrida con Capacitor: web HTML5/CSS3/ES-modules vanilla en
  WebView, con puentes nativos Java para portapapeles, compartir, idioma y
  links externos. Tarot Rider-Waite, I Ching y Carta Astral con análisis IA.
  Sin frameworks ni Jetpack Compose."
